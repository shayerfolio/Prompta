CUEBASE 0.8 — YOUR EXISTING GITHUB + CLOUDFLARE PAGES SETUP

Your address stays: https://cuebase.pages.dev/
Your existing database stays: prompta-library
The GitHub repository can stay named Prompta.

1. UPDATE YOUR GITHUB PROJECT

Extract the whole ZIP into Downloads, outside your existing project folder.
Open the extracted Cuebase folder and double-click Update-Cuebase.bat.

When it asks for the existing project folder, use:
C:\Users\MSI\Documents\GitHub\Prompta
If that folder is already shown, press Enter.

This updates the complete project, saves replaced files in a local backup,
and removes the old deployment files. It does not publish anything.

Open GitHub Desktop and select your Prompta repository.
Review the changes, enter the summary "Switch to Cuebase Pages", click
Commit, then Push origin. Include all project folders shown in the changes.

2. OPEN YOUR EXISTING CLOUDFLARE PAGES PROJECT

Cloudflare > Workers & Pages > cuebase
Use the existing Pages project. Keep its existing GitHub connection.

Under Settings > Build, check:
  Build command:          npm run build
  Build output directory: dist
  Root directory:         leave blank
  Framework preset:       None (if a preset is requested)

3. SET THE DATABASE AND PIN

Use the Production environment.

Settings > Bindings > Add > D1 database:
  Variable name: DB
  Database:      prompta-library
Save.

Settings > Variables and Secrets > Add:
  Name:  PIN
  Value: your chosen PIN, 6 to 12 digits
Choose Secret / Encrypt, then Save.

Only PIN and DB are required. No database ID, PIN hash, session secret,
Cloudflare login command or manual database setup is needed.

4. DEPLOY THE UPDATED COMMIT

If the push already started a build, let it finish. After saving the settings,
open Deployments and retry the deployment for your NEW Cuebase commit.
Check the commit message. Retrying an old commit rebuilds the old app.

When the deployment succeeds, open https://cuebase.pages.dev/ and enter the PIN.
Open the same address on your phone and check that both show the same prompts.

If your old library has prompts, choosing the existing prompta-library database
keeps them. Do not delete the database or clear browser data while moving over.

AFTER IT WORKS

Keep using GitHub Desktop > Commit > Push origin for later code updates.
To change the PIN: edit the PIN secret in cuebase, save, and deploy again.
You do not need npm run launch.

The older prompta Worker is a separate app. Retire it only after Cuebase works;
docs/SETUP.md explains this final cleanup and keeps your database intact.
Scheduled cloud backups are not enabled by this Pages setup. JSON export works.

Need more detail? Open docs/SETUP.md. Local preview is optional; use
Start-Cuebase.bat only if you want to run a separate test library on this PC.
